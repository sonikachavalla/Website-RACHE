## 🎨 Customization Guide

### Change Colors
Edit `styles.css` at the top:
```css
:root {
    --primary-purple: #9F7AEA;
    --secondary-purple: #B794F6;
    /* etc. */
}
```

### Add Content
- **Team members**: Edit `team.html`
- **Projects**: Edit `projects.html`
- **Events**: Edit `events.html`
- **Gallery photos**: Replace gradient placeholders in `gallery.html`

### Update Contact Info
Edit footer in ANY page, changes will apply when you copy footer to all pages.
